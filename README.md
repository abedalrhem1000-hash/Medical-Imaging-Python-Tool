#  Medical Imaging & PACS Workstation (Python)

A professional interactive 3D medical imaging workstation prototype built with Python for loading, visualizing, and analyzing multi-modality medical datasets (DICOM and NIfTI formats).

## Key Features:
- **Multi-Panel Layout:** Axial, Coronal, Sagittal, and MRS Spectrum synchronized viewports.
- **Interactive Navigation:** Mouse wheel scrolling, keyboard shortcuts, and dynamic vertical slide scrollbars.
- **Image Enhancement:** Real-time Brightness, Contrast, and Sharpness tuning using SciPy and NumPy.
- **Quantitative ROI Analysis:** 3D Voxel spatial tracking, ROI region statistics (Mean, Std, SNR), and dynamic metadata rendering.
- **Workflow:** AI-assisted rapid prototyping and custom DICOM/NIfTI parsing.

## Tech Stack:
- Python, Tkinter, Matplotlib, NumPy, SciPy, NiBabel, PyDICOM.
